This repo is a fork of the Planets.nu plugin https://greasyfork.org/en/scripts/5994-planets-nu-enemy-ship-list-plugin.
This fork fixes one outstanding issue of the original where the png for the enemy ships is no longer hosted by planets.nu

Added a new feature to see the historical movement of enemy ships. You can filter by all, by player, or by ship. You can show the path range for specific time windows.
